# CollectorCheck Architecture

CollectorCheck v1 uses a deterministic, minimal‑systems architecture designed for clarity, auditability, and provenance integrity.

## Overview

The architecture consists of:

- A lightweight Flask backend  
- Deterministic verification services  
- Structured receipt ingestion  
- Continuity record generation  
- A simple frontend viewer
