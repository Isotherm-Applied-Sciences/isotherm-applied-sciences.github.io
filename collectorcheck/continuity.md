# Continuity Model

CollectorCheck is part of the Isotherm continuity stack, providing deterministic provenance and identity continuity for collectors, archivists, and institutions.

## Purpose

The continuity model ensures that every verified receipt produces:

- a deterministic continuity record
- a stable identity reference
- a provenance chain
- audit‑friendly metadata

## Components

### 1. Continuity Record
A structured, deterministic record generated after each verification.

### 2. Identity Reference
A stable identifier linking the receipt to the collector or institution.

### 3. Provenance Chain
A transparent chain documenting authenticity, verification steps, and metadata.

### 4. Ledger Integration
CollectorCheck can integrate with Dadtabus for identity continuity and long‑term provenance storage.

## Deterministic Behavior

The continuity model guarantees:

- same input → same continuity record
- transparent logic
- no heuristics
- no cloud dependency
- fully auditable workflows

## Status

This continuity model defines the foundation for CollectorCheck v1 and will expand as the provenance pipeline matures.
