# CollectorCheck

CollectorCheck is a free, open‑source receipt verification gateway designed for collectors, archivists, and institutions.  
It provides provenance assurance, authenticity checks, and continuity records.

## Repository
https://github.com/Isotherm-Applied-Sciences/collectorcheck

## Status
Active development — MVP backend and frontend architecture in progress.

## Roadmap
- Receipt ingestion and parsing
- Provenance verification pipeline
- Continuity record generation
- Public verification gateway
- Identity substrate integration (Dadtabus)

## Purpose
CollectorCheck strengthens authenticity and provenance integrity across digital and physical ecosystems.  
It is part of the broader Isotherm continuity stack.
